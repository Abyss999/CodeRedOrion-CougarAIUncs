# Food Waste Reducer

iOS app that tracks what's in your fridge and pantry, predicts when it expires, flags spoilage from photos, suggests recipes from what's about to go off, and lets friends and groups share surplus. Every removal records an outcome (used / donated / thrown out), which feeds an Impact Dashboard: food saved, money saved, CO₂ avoided.

- Start here: [`HANDOFF.md`](HANDOFF.md) (current status) and [`docs/SETUP.md`](docs/SETUP.md) (how to run it).
- Agents: read [`CLAUDE.md`](CLAUDE.md) first.

**Dataset attribution:** the vision models are trained in part on CC BY 4.0 datasets: Fridge objects (wajeeha workspace, Roboflow), Hien_Fridge (gracelearning, Roboflow) and VegQual (figshare). We also use a CC0 fresh/stale set from Kaggle. Authors, links and our changes are listed in [`docs/ML.md`](docs/ML.md#attributions).
